Patreon Live Chat+

Réponses @pseudo, autocomplétion et émotes 7TV sur les lives Patreon (navigateur web). Les viewers sans l’extension voient le nom texte des émotes.

Installation (mode développeur)

  • Firefox / Zen : about:debugging → « Charger un module temporaire » → manifest.json
  • Chrome / Brave / Edge / Opera : chrome://extensions → mode développeur → « Charger l’extension non empaquetée »
  • Safari (Mac/iPhone) : projet Xcode avec « Web Extension » (empaquetage séparé)

Page créateur : patreon.com/cw/Doflamingoh — pendant un live, ouvrez le live dans le navigateur (pas l’app mobile Patreon).
