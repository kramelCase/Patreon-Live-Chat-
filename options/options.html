Patreon Live Chat+

Le chat du live

Ces ajouts au chat des lives Patreon ne sont visibles que pour toi.

Répondre

Clique sur le pseudo d’un message : un bouton Répondre apparaît. Il écrit dans le champ @ suivi du nom complet, même s’il contient des espaces.

Autocomplétion

En tapant @ puis quelques lettres, tu vois les personnes présentes dans le chat. La touche Entrée insère le nom choisi, sans envoyer le message.

Mise en avant

Les messages qui te répondent sont mis en avant. Les autres restent tels quels.

Émotes 7TV

Les noms d’émotes 7TV s’affichent en image. Les spectateurs qui n’ont pas l’extension continuent de voir le texte.

Utiliser le chat

  1. Ajouter les émotes 7TV d’un streameur Twitch

    Écris le nom de sa chaîne Twitch, pas son pseudo Patreon. Ses émotes s’ajoutent au chat. Tu peux en ajouter plusieurs.

  2. Recharger la page du live pour les voir

    Recharge la page Patreon du live. Les émotes, Répondre et les suggestions apparaissent alors. Personne d’autre ne les voit.

  3. Choisir la taille et parcourir les émotes

    Règle la taille affichée dans le chat, vérifie l’aperçu, puis ouvre la liste de chaque streameur ou les émotes globales.

    C’est la taille affichée dans le chat. Recharge la page du live pour l’appliquer.

    Salut 7TV tout le monde

À propos

Réponses, autocomplétion et émotes 7TV sur les lives Patreon ouverts dans le navigateur.

  • Firefox / Zen : about:debugging → charger un module temporaire → manifest.json
  • Chrome, Edge et Opera demandent une variante dont l’arrière-plan est un service worker.
  • Safari demande un projet Xcode « Safari Web Extension », sur un Mac.
  • Pendant un live, ouvre la page du live dans le navigateur, pas l’application mobile.
